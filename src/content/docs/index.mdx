## 🌟 Key Capabilities

<CardGrid stagger>
	<Card title="Deep AST Parsing" icon="puzzle">
		Automatically parses codebases using `web-tree-sitter` and official WASM language grammars to understand structural definitions.
	</Card>
	<Card title="Semantic TypeGraph DB" icon="database">
		Persists structural data into a SQLite database (`graph.db`) utilizing the `@nicia-ai/typegraph` ORM layer.
	</Card>
	<Card title="Leiden Modular Clustering" icon="rocket">
		Identifies functional communities and microservices natively via the Leiden algorithm, dynamically configurable.
	</Card>
	<Card title="Premium Visualization" icon="magnifiers">
		Generates a stunning, interactive HTML dashboard powered by Vis.js for deep architectural navigation and insights.
	</Card>
</CardGrid>

## Built for AI

Berkelium exposes core tools natively over the **Model Context Protocol (MCP)**, allowing agents like Gemini and Claude to dynamically query imports, relationships, and boundaries.

<CardGrid>
	<Card title="Standardized MCP Interface" icon="setting">
		Exposes `berkelium_init`, `berkelium_update`, and search tools straight to your LLM's context window.
	</Card>
	<Card title="Gemini CLI Native" icon="laptop">
		Works out-of-the-box as a Gemini CLI extension via the `gemini-extension.json` config.
	</Card>
</CardGrid>
