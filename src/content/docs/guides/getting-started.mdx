Berkelium is a powerful Model Context Protocol (MCP) server that constructs a queryable, semantic **Knowledge Graph** of any codebase.

## Prerequisites

Before installing Berkelium, ensure you have:
*   [Node.js](https://nodejs.org/) (v18 or higher recommended)
*   [pnpm](https://pnpm.io/) (or `npm`/`yarn`)

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BerkeliumLabs/Berkelium-dev.git
   cd Berkelium-dev
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   ```

## Initializing a Project

To initialize Berkelium on your target codebase, run the `bk init` command inside your project directory (if configured), or invoke the `berkelium_init` MCP tool.

Berkelium will:
1. Parse your project using `web-tree-sitter`.
2. Generate the `.berkelium` directory containing `graph.db`, `graph.json`, and `graph.html`.
3. Add `.berkelium` to your `.gitignore`.
