---
title: CLI Commands
description: Reference for custom command shortcuts
---

Berkelium configures custom extension prompts under `commands/bk/` for rapid execution from AI terminals.

### `bk init`
Triggers the `berkelium_init` tool and provides the assistant with clean instructions on how to handle the parsing result and notify the user. Run this when setting up Berkelium on a project for the first time.

### `bk update`
Triggers the `berkelium_update` tool. This command ensures any recent structural code modifications are captured, handles automatic graph backups, and guarantees the `.berkelium` visualization database remains perfectly synchronized with your actual codebase.
